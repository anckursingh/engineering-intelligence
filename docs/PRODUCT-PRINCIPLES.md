# Product Principles

## 1. AIKOQL stays a database

Engineering semantics never enter AIKOQL.

## 2. Evidence before insight

Every important conclusion must be traceable to source evidence.

## 3. Explain relationships, not just metrics

A number is an observation. The product value is understanding relationships that may explain it.

## 4. Measure systems, not people

Avoid default individual productivity scores.

Prefer:

- team flow
- system constraints
- review capacity
- quality
- reliability
- AI workflow outcomes

## 5. Separate observation from inference

The product must distinguish:

- observed
- calculated
- inferred
- hypothesized

## 6. No false causality

Correlations and temporal changes are not automatically causal.

## 7. AI is a development mode, not a single metric

AI-assisted, AI-generated and agentic development should be modeled separately.

## 8. Vendor neutrality

AI agents and coding assistants are replaceable sources.

Do not make the ontology depend on one AI vendor.

## 9. Source independence

GitHub/Jira/etc. are sources, not the canonical model.

## 10. Small first

Start with GitHub + Jira + one AI source.

Expand only after the canonical model proves useful.
