# Roadmap

## Phase 0 — Product validation

- PRD
- competitive teardown
- ontology
- AI development model
- AIKOQL integration contract
- MVP acceptance criteria

Exit:
Product thesis is clear and scope is constrained.

## Phase 1 — Knowledge foundation

- Go service skeleton
- GitHub connector
- Jira connector
- identity resolution
- canonical ontology
- AIKOQL persistence
- provenance
- checkpoints

Exit:
A real organization's engineering graph can be reconstructed.

## Phase 2 — AI development

- one AI telemetry integration
- AIInteraction
- AIAgent
- AgentRun
- AI contribution attribution
- agent outcome

Exit:
AI-assisted and agentic activity can be connected to engineering outcomes.

## Phase 3 — Metrics

- flow
- quality
- reliability
- AI metrics
- temporal comparisons
- evidence lineage

Exit:
Metrics are deterministic and reproducible.

## Phase 4 — Engineering intelligence

- investigation API
- root-cause exploration
- evidence-backed explanations
- board view
- manager view

Exit:
Users can investigate changes without manually joining multiple systems.

## Phase 5 — Agent

- natural-language questions
- query planning
- graph traversal
- semantic retrieval
- evidence synthesis
- confidence and limitations

Exit:
Agent answers are reproducible from engineering knowledge.

## Phase 6 — Enterprise

- SSO
- SCIM
- RBAC
- audit
- data residency
- private deployment
- more connectors
- enterprise support

## Explicitly deferred

- individual productivity scores
- employee ranking
- autonomous production changes
- dozens of connectors before product/ontology validation
- custom AI model training
- engineering logic inside AIKOQL
